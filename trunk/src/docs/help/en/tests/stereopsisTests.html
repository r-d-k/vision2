Tests for stereopsis

Stereopsis is hightest, third step of binocular vision. It's process of perceiving depth by analizing images perceived by eyes from slighty different directions.

To test stereopsis identical images are presented for left and right eye. Images differ each other with presentation direction. If patient can't see 3-dimensional object, he/she don't have ability to stereopsis.

Program includes 5 test checking stereopsis. They consists of 2 identical elements presented from different directions:

  • circles,
  • bucket,
  • eyes,
  • pick-a-stick,
  • figures.

Exemplary on picture 1 there is element visible for one eye and on picture 2 - visible for second eye. Pacient with ability to stereopsis should perceive this images like 3-dimensional.

Patient can correct his phoria by moving one of elements in whichever direction.

  • up by pressing key ↑
  • down by pressing key ↓
  • left by pressing key ←
  • right by pressing key →

Phoria is calculated from following equation on the basics of movement suitable element x and distance from monitor l.
