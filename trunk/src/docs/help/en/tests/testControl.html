Test control

Options available in classical and synoptiscope-like tests

While displaying classical or synoptiscope-like test there are following options available:

  • ↑: Move up element visible for one eye.
  • ↓: Move down element visible for one eye.
  • ← : Move left element visible for one eye.
  • → : Move right element visible for one eye.
  • ENTER: Ends test and save current result. Results are available in "Results" tab.
  • ESC: Cancel test. Result is lost.
  • SPACE: Following space pressing show or hide current result on upper-left corner of screen. Equals choosing option "Show result on test" in "Configuration" menu.
  • P: Following pressing of key "P" causes polarisation switch. Element visible for left eye so far become visible by right eye and vice-versa. Equals choosing option "Polarisation change" in "Configuration" menu.


Options available in vectographical and random dot tests

Vectographical and random dot tests work slightly different from the rest. Default number of re-run is 4. This amount can be changed in "Tests" tab in "amount of repetitions" fields. Additionally keys with arrows don't move anything but serve as mean to indicate stereoscopic triangle (seems to be above or under screen surface).

While displaying vectographical and random dot test there are following options available:

  • ↑ : Marking upper triangle. Result of this single test is immediately saved and next test is displayed instead mesurement is ended.
  • ↓ : Marking lower triangle. Result of this single test is immediately saved and next test is displayed instead mesurement is ended.
  • ← : Marking left triangle. Result of this single test is immediately saved and next test is displayed instead mesurement is ended.
  • → : Marking right triangle. Result of this single test is immediately saved and next test is displayed instead mesurement is ended.
  • ESC: Cancel test. Result of current test isn't saved but previous results of previous tests in series are already saved.
  • SPACE: Following space pressing show or hide current result on upper-left corner of screen. Equals choosing option "Show result on test" in "Configuration" menu.
  • P: Following pressing of key "P" causes polarisation switch. Element visible for left eye so far become visible by right eye and vice-versa. Equals choosing option "Polarisation change" in "Configuration" menu.


Options available in dual-monitor work

Dual-monitor work can be activated by choosing option "Dual monitor work" from "Configuration" menu. Before activating this mode one should configure operating system according to recommendations in section System settings.

During dual-monitor work more options are available. On examinator monitor additional window is showing presenting actual result. Pressing button "Cancel" on that windows cause test termination.
