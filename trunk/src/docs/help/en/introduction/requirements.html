Requirements

To run this program you need:

  • Shutter glasses: VRJoy, eDimensional (http://www.edimensional.com) or other that can present for one eye view from odd screen lines and for second eye view from even screen lines (interleaved line stereo)
  • CTR Monitor to present tests, screen size 17 inches, minimal refresh rate for resolution 800*600 shoud be 100 Hz.
  • Second monitor to present examinator interface (optional).
  • Computer that meets following requirements:
    • Keyboard connector PS/2: can be occupied by keyboard (only for VRJoy shutter glasses).
    • Hard disc: 120 MB free space.
    • Processor: 500 MHz or faster.
    • Memory: 256 MB or more
    • Operating system: Windows, Linux, Solaris or MacOS (shutter glasses made by eDimensional work only with Windows)
    • Java: installed Java Runttime Environment version 1.6.0_13 or higher.
