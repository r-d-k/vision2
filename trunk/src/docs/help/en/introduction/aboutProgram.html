About program

Vision2 is Java program written as part of my diploma thesis. It serves as tool for ophthalmologists and other vision testing professionals. It's useful for a variety of ophthalmology testing applications related to stereo vision. It implements many of classical tests but also new types of vectographic and random dot exams.

The most important feature is ability to move parts of displayed test. Subject with binocular vision errors perceives deformed test. But he/she can "repair" test using arrows keys. Program then evaluate size of vision error.
