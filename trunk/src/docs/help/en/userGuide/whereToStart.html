Where to start

To start using program follow this steps:

  • Check hardware and software requirements described in section "Requirements"
  • Connect shutter glasses to computer as described in section "Connecting glasses".
  • After turning on computer set resolution and refresh rate as described in section "System settings".
  • Insert enclosed compact disk in reader. Start program by double-click on file vision2.jar in program catalog. If program doesn't start try launching start.bat. If program still doesn't start - check if you have Java Runtime Environment installed. It's available in java folder on enclosed disc.
  • All program functions are included in 5 tabs sorted by typical use order. You should start from tab "Settings";, next "Patient" etc. Detailed description of all user interface's elements can be found in chapter "User interface".
  • You can launch tests by clicking on icons in tab "Tests" or "Synoptiscope". Detailed description of all tests can be found in chapter "Test description".
  • Program can be installed on hard disc. Just create folder vision2 in Program files and paste vision2.jar file inside (from enclosed disc or from project website). Then create shortcut to vision2.jar file and move it to desktop or to Start Menu.
  • Newest version of this program can be downloaded from http://vision2.googlecode.com.
