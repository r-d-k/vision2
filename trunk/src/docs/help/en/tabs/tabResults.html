Tab "Results"

Picture 1 shows tab "Results". It allows viewing examination results. They are presenting in chronological order in table split into 4 colums:

  • Date: Date and time of examination.
  • Test name: Name of test, i.e. "Cross test" or "Cross test with central stimulus".
  • Examinated disease: Description of examinated error, i.e. "horizontal/vertical phoria".
  • Result: Result, i.e. "-12.38'/14.44'".
